# Передача работы: АМТЗ + ЗСБ, Таймыр (профили 6 и 2)

Этот файл — для новой (локальной) сессии Claude Code. Прочитай его целиком перед работой.
Предыдущая работа шла в облачной сессии; её промежуточные файлы пользователь скачал архивом
`mt_inv_results_bundle.zip` (см. раздел «Где что лежит»).

## Правила проекта

- Ветка `mt-inv-gui`. PR не создавать без просьбы.
- Полевые данные пользователя (EDI, ЗСБ, временные ряды, результаты) **в репозиторий не коммитить**;
  `results*/` в `.gitignore`.
- Палитра сопротивлений: **красный — высокоомное, синий — низкоомное** (`jet` по умолчанию).
- Ответы — по-русски, честно про неопределённость (пользователь просит оценки доверия 0–100).
- Перед коммитом: `python -m pytest -q tests` (≈1.5 мин, 25 тестов).

## Что умеет программа (`mtinv/`)

| Модуль | Что делает |
|---|---|
| `edi.py`, `mtdata.py` | EDI (Z, типпер, ρ/φ-only, cp1251), ρa/φ, поворот, фазовый тензор, статический сдвиг `Station.ss`; `bad_points`/`auto_mask` (отбраковка по компонентам, узкое и широкое окно), `fill_gaps`/`unfill_gaps` (заполнение коротких пропусков прямой) |
| `inv1d.py` | 1D МТ, Оккам (`occam_core`, можно задать сетку λ) |
| `inv2d.py`, `_simpeg_fast.py` | 2D SimPEG TE/TM в ln ρa, явный Якобиан (исправлен случай одной станции на частоте), глубинность по чувствительности, `beta_min_ratio` + остановка при застое RMS (защита от «раскачки» модели) |
| `tem.py`, `tem_fast.py` | ЗСБ: формат, ρτ, быстрая прямая задача петли (`LoopTEMForward`) с аналитическим Якобианом |
| `tsikl.py` | Цикл `.pod`: слияние токов, сдвиг времени малого тока, брак по ВП (`ip_reject`), шумные хвосты, ПДИ-50 как точечный датчик, `average_pairs` |
| `joint1d.py` | 1D ЗСБ, совместная 1D, сдвиг АМТЗ по модели ЗСБ (`static_shift_from_model`) |
| `tem_lci.py` | LCI — латерально-связанная инверсия ЗСБ профиля; + фазы АМТЗ (по Meju) или ρa+фазы с подбором k на станцию |
| `statshift.py` | статистическая нормализация (Пальшин/Яковлев) |
| `gui/` | PySide6: карта, кривые, псевдоразрезы, 1D, 2D, ЗСБ; `run.bat` |

## Данные и приборы

- АМТЗ: прибор **Норд**, временные ряды (~600 ГБ) есть у пользователя; EDI получены обработкой
  с удалённой базой (пользователь называет «RERH» — уточнить, что это и в какой программе).
- ЗСБ: Цикл, петля 100×100, приёмник ПДИ-50 (экв. 50×50, 1 виток), старт 50 мкс; центральная
  + 2 разносные точки на петлю; большой/малый ток, 3 дубля. Обработанные геофизиком файлы
  `.c2d/.d2d` (годные) и `.dod` (брак). Единицы — мВ (документация ПОДБОР).
- Скважин нет. Эталонного замера ЗСБ нет.
- Профиль 6: АМТЗ ст. 60–665 (≈12.9 км, азимут 145°), ЗСБ ПР6 (пикеты 06-215…06-535, петли 22–53).
- Профиль 2 АМТЗ (ст. 20…250) + ЗСБ ПР1 рядом; новые 5 разносов ПР2 (02-26…02-30).
- Сетка АМТЗ другой организации по профилю 6 (`p6.dat`, Surfer XYZ): X_их = X_наш + 360 м
  (±50 м; X_наш — проекция на линию от ст. 60), Y — отметка.

## Главные результаты и степень доверия

**Профиль 6**
- ЗСБ: наша обработка ≈ геофизик (±5 %); брак по ВП 13/14 совпадает (расходятся 06-260, 06-380).
- Запад (их X 4.6–8.2 км) — высокоомный (тысячи Ом·м) сверху, восток (8.3–11 км) — проводник
  10–150 Ом·м от поверхности до ~600–900 м; граница ≈8.2 км. Доверие ~65.
- ρa АМТЗ завышено относительно ЗСБ: медиана k = 0.42 (запад 0.6, восток 0.3, у контакта
  8.4–8.8 км до 0.05). На профиле 2 медиана k = 0.87 → если ЗСБ снимался тем же прибором,
  калибровка ЗСБ, вероятно, в порядке, и завышение на профиле 6 — сдвиг/геология (проверить!).
- Старая 2D АМТЗ (RMS 2.20) была недорегуляризована (β до 1e-10, модель до 1e5 Ом·м) —
  **не использовать**. Исправленная 2D `safeB` (ρa TE 10 %, TM — фазы, RMS 2.49) согласуется с ЗСБ
  (corr 0.55). Глубже 0.7 км и на западе (не 2D: XY/YX ×3) доверие ~35.
- Совместная LCI J1 (ЗСБ + фазы АМТЗ) и J2 (с k): восток согласован (RMS ЗСБ ~1.0–1.3,
  АМТЗ ~1.5–1.7), на западе конфликт (RMS ЗСБ ~2) — 1D не хватает.
- Узкая высокоомная зона ~7.9–8.3 км — неуверенная (~30).
- ВП: 16 брак (центр), 3 слабая, 10 «возможна» (разносы); полоса 06-230…06-390 на западе.

**Профиль 2**: 2D-friendly (простирание ≈ ⟂ профилю); запад высокоомный / восток проводящий,
граница ~3 км (~70); линза 0.4–0.5 км на 4–7 км неустойчива (~25).

**Системные проблемы**: RMS 2D не опускается ниже ~2.2 — вероятно, погрешности в EDI занижены;
внешней проверки (скважины, эталон) нет.

     реальная ошибка; сравнить с ошибками в EDI;

3. ЗСБ без эталона: модель центральной установки должна предсказывать разносы той же петли;
