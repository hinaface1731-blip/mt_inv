# MT-Inv — графическая оболочка для МТ-данных (EDI)

Бесплатная программа, в которой можно загрузить EDI, посмотреть все параметры кривых,
нарисовать станции на карте, собрать профиль и получить 1D- и 2D-разрезы без
программирования. Внутри используются открытые библиотеки: **SimPEG** (2D-инверсия),
**NumPy/SciPy**, **matplotlib**, **PySide6 (Qt)**.

## Установка (Windows)

1. Установите **Python 3.11 или 3.12** с <https://www.python.org/downloads/>.
   При установке отметьте галочку **«Add python.exe to PATH»**.
2. Скачайте этот репозиторий (Code → Download ZIP) и распакуйте.
3. Дважды щёлкните **`install.bat`**. Он создаст папку `.venv` и поставит все библиотеки
   (это займёт несколько минут, нужен интернет).
4. Для запуска используйте **`run.bat`**. Если что-то падает, запустите **`run_debug.bat`**:
   в консоли будет видна ошибка.

Linux/macOS: `pip install -r requirements.txt pydiso` и потом `python run.py`.

Для проверки в папке `demo_data/` лежат 15 синтетических EDI (профиль на Таймыре,
2D-модель с проводником на глубине 2–6 км и изолятором справа), а в `demo_data/zsb/` —
15 синтетических зондирований ЗСБ рядом со станциями. На станциях TMR003, TMR007,
TMR011 и TMR013 кривые АМТЗ специально испорчены статическим сдвигом (ρxy/ρyx ×0.35/0.5,
×2.5/1.8, ×0.5/0.4, ×3.0/2.2), чтобы было на чём проверить его исправление по ЗСБ.
Пересоздать данные: `python tools/make_demo.py`.

## Что умеет

| Вкладка | Что там |
|---|---|
| **Кривые** | ρa и фазы (XY, YX, Det, SSQ, XX, YY) с ошибками, поворот тензора, типпер, фазовый тензор (Φmax/Φmin, skew β, Swift skew, простирание). Щелчок по точке исключает частоту из инверсии. |
| **Карта и профили** | Станции на карте (подложки OSM, OpenTopoMap, спутник Esri; нужен интернет, тайлы кэшируются в `~/.mtinv/tiles`), индукционные стрелки и эллипсы фазового тензора на выбранном периоде. Профиль собирается из выделенных станций (щелчками или рамкой); линия проводится по МНК. |
| **Псевдоразрезы** | ρa и фазы вдоль профиля по периодам. |
| **1D инверсия** | Инверсия Оккама (гладкая модель) по одной станции + трансформация Ниблетта–Бостика. Кнопка «Все станции профиля» строит «сшитый» 1D-разрез. Экспорт в CSV. |
| **АМТЗ + ЗСБ** | Загрузка ЗСБ и привязка к МТ-станциям (автоматически — к ближайшей станции, или вручную). Инверсия Оккама по ЗСБ. Статический сдвиг АМТЗ по модели ЗСБ: одна станция с просмотром или все привязанные сразу. Совместная инверсия АМТЗ+ЗСБ с подбором сдвига. Кнопка «Сравнить» строит три модели на одной сетке: только АМТЗ, только ЗСБ, совместная. |
| **2D инверсия** | SimPEG, моды TE/TM вместе или по отдельности, ρa + фаза. Простирание задаётся вручную, перпендикулярно профилю или по фазовому тензору. Разрез перерисовывается после каждой итерации, есть кнопка «Стоп». Подбор данных показан псевдоразрезами (наблюдённые / модельные / невязки) и кривыми по станциям. Результат сохраняется в `.npz`, экспортируется в CSV (x, глубина, ρ, широта, долгота). |

Проект (список файлов, исключённые точки, профили) сохраняется в `.json`
через «Файл → Сохранить проект».

## Про EDI

Читаются:
* импеданс `>ZXXR/ZXXI/ZXX.VAR …` (ошибки — дисперсии, как в стандарте);
* типпер `>TXR.EXP/TXI.EXP/TXVAR.EXP …`;
* файлы только с `>RHOXY/>PHSXY` (+ `.ERR`): импеданс восстанавливается из них;
* координаты `LAT/LONG/ELEV` из `>HEAD` или `REFLAT/REFLONG` из `>=DEFINEMEAS`,
  как в градусах (`72.3`), так и в виде `72:18:00.0`.

Не поддерживаются EDI, где лежат только спектры (`>SPECTRA`). Если ваш файл не
читается, пришлите его шапку, и я добавлю его формат.

Соглашения: x — север, y — восток, Z в мВ/км/нТл, ρa = 0.2·T·|Z|². Фаза YX
переносится в первый квадрант (+180°).

## Комплексирование АМТЗ и ЗСБ

Как это устроено в программе:

1. **Статический сдвиг.** Сначала делается 1D-инверсия ЗСБ. Для её модели решается
   прямая задача МТ и считается ρa на частотах станции. Берутся только частоты, на
   которых глубина Бостика модельной кривой меньше глубинности ЗСБ: там МТ «видит»
   только надёжно изученную ЗСБ верхнюю часть разреза. На этих частотах наблюдённая
   ρxy и ρyx сдвигается по вертикали до совпадения с модельной (медиана отношения в
   логарифмах, отдельно для XY и YX). Фаза сдвигом не искажается и не меняется.
   Если общих частот нет, программа предупреждает и берёт 3 самые высокие частоты
   АМТЗ.
2. **Применённый сдвиг** хранится у станции как пара множителей ρxy×k, ρyx×k. Он
   учитывается везде: в кривых, псевдоразрезах, 1D и 2D-инверсии, при экспорте EDI
   и сохраняется в проекте. Множители можно задать и вручную на вкладке «Кривые».
3. **Совместная 1D-инверсия.** Одна слоистая модель подбирается сразу под ρa и фазу
   АМТЗ и под сигнал ЗСБ. Верх разреза определяет в основном ЗСБ, низ — АМТЗ, и это
   снимает эквивалентность раздельной интерпретации. С галочкой «подбирать
   статический сдвиг» множитель k для ρa АМТЗ подбирается как отдельный параметр.

**Формат файлов ЗСБ** — текст, по одному зондированию на файл. Колонки
«время  сигнал  [ошибка]» через пробел, табуляцию или `;`; допускается десятичная
запятая. Строки, начинающиеся с `#`, — комментарии. Параметры можно указать в шапке,
иначе их спросит диалог импорта:

```
# NAME = ZSB007
# LAT = 72.330070          (или 72:19:48.25)
# LON = 95.736513
# TX_SIDE = 200            сторона квадратной генераторной петли, м
# RX_AREA = 10000          эффективная площадь приёмника (витки × площадь), м²
# CONFIG = central         central | coincident
# TIME_UNITS = ms          ms | us | s
# DATA = emf_uV_A          emf_uV_A | emf_V_A | dbdt_nT_s_A | dbdt_T_s_A | rho_tau
# RAMP_US = 0              длительность выключения тока, мкс (0 = ступенька)
# LINK = TMR007            (необязательно) МТ-станция
0.01   6.216e+05   1.88e+04
...
```

Ограничения ЗСБ:
* прямая задача — SimPEG, круглая петля той же площади, что квадратная;
* совмещённые петли считаются как центральная установка. На поздней стадии это
  точно, на самых ранних временах — приближённо;
* нелинейный ток выключения задаётся только линейной рампой.

## Советы по 2D-инверсии

* **Простирание.** В TE электрическое поле идёт вдоль простирания, профиль должен
  идти поперёк него. Кнопка «⟂ профилю» ставит простирание = азимут профиля − 90°.
  Кнопка «ФТ» берёт медианное простирание по фазовому тензору (у него неоднозначность
  90°, поэтому выбирается вариант, ближайший к перпендикуляру профиля).
* **Сначала посмотрите псевдоразрезы и фазовый тензор.** Если β > 3–5°, среда
  трёхмерна и 2D-результат надо воспринимать осторожно.
* **Ошибки.** Минимальные ошибки по умолчанию: 10 % на ρa и 2.9° на фазу. Лучше
  сначала исправить статический сдвиг по ЗСБ (вкладка «АМТЗ + ЗСБ»). Если ЗСБ нет,
  увеличьте ошибку ρa (до 20–50 %), чтобы модель больше опиралась на фазы.
* **Скорость.** Время зависит от числа станций, частот и ячеек. На тестовом профиле
  (15 станций, 29 частот, TE+TM) итерация считается примерно за 10–30 с. Для
  предварительного просмотра можно уменьшить «Частот на декаду» до 3–4 и «Ячеек
  между ст.» до 2.
* **Рельеф** пока не учитывается: поверхность плоская.

## Структура кода

```
mtinv/edi.py          чтение/запись EDI
mtinv/mtdata.py       Station: ρa/фазы, инварианты, поворот, фазовый тензор, стрелки
mtinv/inv1d.py        1D прямая задача, Бостик, Оккам
mtinv/inv2d.py        подготовка данных, сетка, 2D-инверсия SimPEG
mtinv/tem.py          ЗСБ: чтение, ρτ, прямая задача (SimPEG 1D)
mtinv/joint1d.py      инверсия ЗСБ, статический сдвиг по ЗСБ, совместная инверсия
mtinv/_simpeg_fast.py ускорение SimPEG (явная матрица чувствительности)
mtinv/profile.py      профили и проекция станций
mtinv/tiles.py        подложки карт
mtinv/gui/            интерфейс (PySide6 + matplotlib)
tests/                тесты (python -m pytest tests)
```
